# Memo — интерактивный словарь курса

Русскоязычный статический сайт для GitHub Pages. Сборка, установка пакетов, серверная база и ключи доступа не нужны.

## Что входит в проект

```text
memo/
├── index.html
├── cards.json          ← опубликованный набор
├── .nojekyll
├── README.md
└── assets/
    ├── app.js
    └── style.css
```

Исходные файлы и заполненные карточки из прежней беседы не были доступны при подготовке этой версии. Интерфейс воссоздан по требованиям. Начальный `cards.json` пустой: вы можете сразу создавать свой словарь. Старые данные автоматически не переносятся; импорт поддерживает формат, описанный ниже.

## Первая публикация на GitHub Pages

1. Распакуйте ZIP. Откройте папку `memo`.
2. Войдите на [GitHub](https://github.com), нажмите **+ → New repository**. Введите имя `memo`, выберите **Public**, включите **Add a README file** и нажмите **Create repository**. Публичный репозиторий подходит для GitHub Free.
3. В репозитории выберите **Add file → Upload files**. Перетащите **содержимое** папки `memo`, включая папку `assets`. Не загружайте ZIP и не вкладывайте весь проект в дополнительную папку `memo`.
4. Проверьте, что в корне находятся `index.html`, `cards.json`, `README.md`, `.nojekyll`, а в `assets` — `app.js` и `style.css`. Если скрытый `.nojekyll` не перенёсся, выберите **Add file → Create new file**, назовите файл `.nojekyll` и сохраните его (допустима пустая строка).
5. Внизу загрузки нажмите **Commit changes** и сохраните изменения в ветку `main`. Если GitHub показывает выбор, выберите **Commit directly to the main branch**.
6. Откройте **Settings → Pages**. В разделе **Build and deployment** выберите **Source → Deploy from a branch**. В строке **Branch** выберите **main**, папку **/(root)** и нажмите **Save**.
7. Дождитесь успешного завершения **pages build and deployment** во вкладке **Actions**. На странице **Settings → Pages** появится ссылка **Visit site**. Адрес обычно имеет вид `https://ВАШ-ЛОГИН.github.io/memo/`.
8. Откройте сайт по этой ссылке. Пустой набор при первом открытии — нормальное состояние. Нажмите **Режим преподавателя**, затем **Добавить карточку**.

Настройки публикации сверены с [официальной инструкцией GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site). GitHub может публиковать изменения несколько минут; успешный запуск Actions — ориентир готовности.

## Работа на занятии

- Обычная ссылка всегда открывает **студенческий режим**. Он читает `cards.json` заново при открытии страницы и не использует преподавательскую рабочую копию.
- Нажмите **Режим преподавателя**. При первом входе опубликованный набор копируется в локальную рабочую копию. При следующих входах восстанавливается именно ваша локальная копия, включая пустую, если вы удалили все карточки.
- **Добавить карточку** создаёт новую пустую карточку. Запишите термин, затем определение. Каждое изменение поля автоматически сохраняется; **Готово**, крестик и Escape закрывают окно без отмены правок.
- **Редактировать** позволяет изменить термин, определение и состояние: **Новая**, **Заполнена**, **Проверена**. Состояние выбирает преподаватель вручную. Все три состояния доступны студентам после публикации.
- **Удалить** удаляет карточку из рабочей копии после подтверждения.
- **Повторять рабочую копию** показывает ваши локальные карточки без кнопок редактирования. **Режим преподавателя** возвращает к редактированию. **Опубликованный набор** показывает cards.json для студентов. При открытии страницы по-прежнему загружается опубликованный набор; локальные правки автоматически не публикуются.
- **Проектор** увеличивает текст. **Одна карточка** удобна для обсуждения; **Сетка** показывает весь словарь. Длинные определения не обрезаются: страницу можно прокручивать.
- Карточки переворачиваются нажатием, а при клавиатурном фокусе — Enter или пробелом. Кнопка **Скрыть определения** скрывает определения. Поиск работает по терминам, без учёта регистра.
- **Перемешать** меняет только порядок показа, не порядок в экспортируемом наборе.

## После каждого занятия: обновить набор для студентов

1. В режиме преподавателя нажмите **↓ Скачать cards.json**. Убедитесь, что файл появился в загрузках браузера. Экспорт сам по себе ещё не обновляет сайт.
2. Если браузер назвал файл `cards (1).json`, переименуйте его в **cards.json**. Сохраните дополнительную датированную копию у себя для резервного хранения.
3. Откройте свой репозиторий `memo` на GitHub, вкладку **Code**, ветку **main**, корневую папку.
4. Выберите **Add file → Upload files** и загрузите новый **cards.json** с тем же именем. Это заменит существующий файл. Нажмите **Commit changes**, например с подписью «Карточки после занятия 15 сентября», и сохраните в `main`.
5. Дождитесь успешного запуска **pages build and deployment** во вкладке **Actions**.
6. Откройте обычную ссылку сайта или обновите уже открытую страницу. Проверьте новые карточки в студенческом режиме. Ссылка для студентов остаётся прежней.

Открытые у студентов страницы сами не переключаются на новую версию: попросите обновить их. Приложение запрашивает файл без браузерного кеша, но публикация на стороне GitHub должна завершиться.

## Опубликованный набор и рабочая копия

**Загрузить опубликованный набор** заново скачивает `cards.json` и заменяет им всю рабочую копию после подтверждения. Сначала экспортируйте текущие правки, если они нужны. При ошибке загрузки рабочая копия не меняется. Пустой корректный набор также может заменить вашу копию.

Новая публикация никогда автоматически не перезаписывает уже существующую рабочую копию. Если вы обновили карточки на другом компьютере, на этом компьютере используйте команду загрузки опубликованного набора.

**Восстановить из файла** импортирует экспорт Memo и заменяет рабочую копию после проверки файла и подтверждения. Это удобно для переноса между компьютерами и восстановления резервной копии. Чтобы студенты увидели восстановленные данные, выполните обычную публикацию.

Локальное автосохранение привязано к браузеру, его профилю, адресу сайта и пути проекта. Очистка данных сайтов, приватный режим, новый браузер или другой адрес могут привести к отсутствию рабочей копии. Храните экспорты. При недоступном хранилище приложение показывает явное предупреждение; до закрытия скачайте файл. Работайте в одной преподавательской вкладке: при обнаружении изменений из другой вкладки автосохранение останавливается, чтобы не затереть данные. Экспортируйте нужные правки и перезагрузите страницу.

## Доступ

Преподавательский переключатель — удобный режим интерфейса, а не пароль или авторизация. Любой посетитель может включить его и редактировать **свою** локальную копию. Изменить общий опубликованный набор может только человек с правом записи в репозиторий GitHub. Пароли и токены в сайт не встроены. Содержимое опубликованного `cards.json` общедоступно.

## Проверить сайт на компьютере до публикации

Не открывайте `index.html` двойным щелчком: браузеры ограничивают чтение соседнего JSON через `file://`. Используйте локальный веб-сервер, например при установленном Python:

```powershell
cd "путь\к\папке\memo"
py -m http.server 8000
```

Откройте `http://localhost:8000/`. Чтобы остановить сервер, нажмите Ctrl+C в терминале. Для дальнейшей работы предпочтительно использовать постоянный адрес GitHub Pages: локальная копия с localhost не переносится туда автоматически, её нужно экспортировать и импортировать.

## Формат cards.json

```json
{
  "version": 1,
  "cards": [
    {
      "id": "term-001",
      "term": "Название понятия",
      "definition": "Определение, сформулированное на занятии.",
      "status": "filled"
    }
  ]
}
```

Кодировка UTF-8. `id` — уникальная непустая строка; `term` и `definition` — строки (могут быть пустыми); `status` — `new`, `filled` или `checked`. Лимиты: термин 300 символов, определение 20 000. `version` — число 1. Повторяющиеся идентификаторы и неверные состояния отклоняются. Формат HTML не исполняется: содержимое карточек отображается как обычный текст.

## Если что-то не работает

- **404 / не найден cards.json:** файл должен находиться рядом с `index.html`, имя строго `cards.json` с маленькими буквами.
- **Сайт не открывается:** проверьте `main` и `/(root)` в Settings → Pages, наличие `index.html` в корне и результат Actions.
- **Студенты видят старые карточки:** проверьте имя загруженного файла, завершение публикации и обновите страницу.
- **В преподавательском режиме старые карточки:** это сохранённая рабочая копия. Экспортируйте её при необходимости, затем загрузите опубликованный набор.
- **Ошибка формата:** восстановите исправный экспорт; текущая рабочая копия при неудачном импорте сохраняется.
- **Повреждена локальная копия:** приложение не перезаписывает её автоматически. Сохраните доступные данные экспортом; очистите данные именно этого сайта через настройки браузера, затем восстановите исправный файл. Очистка удаляет локальные данные — опубликованный файл на GitHub остаётся.

Добавьте тестовый термин → введите определение → установите «Проверена» → закройте и снова откройте сайт → войдите в режим преподавателя и проверьте автосохранение → экспортируйте → загрузите файл на GitHub → дождитесь публикации → откройте студенческий режим в другом браузере и проверьте термин, переворот, поиск и показ по одной.
